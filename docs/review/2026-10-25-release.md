# Synthetic release verification, 2026-10-25

PR #152 combines the reviewed snapshots from #142 through #151 and #154,
plus corrective review changes. The application remains a fictional-data
prototype. This note records local release evidence; hosted deployment and
exact-head GitHub checks are separate gates recorded on the PR.

## Corrected behavior

- Decision retry keys accept the identical request and reject conflicting
  invoice, actor, decision, reason, version or simulation parameters without
  returning another decision ID or appending history.
- Summaries, claims and displayed client questions reject unsupported amounts,
  malformed monetary notation, unsupported currencies and approval claims.
- Stored explanations are checked against scoped, dated tool evidence before
  display or new decision binding. Historical failed runs remain withheld;
  immutable explanation rows, decisions and snapshot replay are preserved.
- Memo export regenerates permitted statements from evidence and rejects
  altered amounts, narrative, citations or mandatory gaps.
- Collections comparisons respect when backdated invoices became known.
- Session helpers explicitly wait for a request before checking runtime
  identity and time. Production browser logs contain no prerender or hydration
  errors in the accepted run.
- Login contrast, native demo button names and trend definition-list markup
  pass the targeted automated accessibility checks.

## Hosting and remaining limits

The canonical domain is https://creditdesk.roshanaryal.com. On 25 October 2026,
the custom root redirected to login and the legacy Vercel host returned HTTP
308 to this domain. GitHub's About website was updated and independently
verified. These routing checks do not establish that the final reviewed commit
has been deployed.

Vercel hosts the app and a dedicated Sydney Neon PostgreSQL database holds the
synthetic fixtures and imported immutable history. Routine releases must not
reseed it. Public demo sessions are signed, short-lived and read-only.

Self-selected personas are not enterprise identities. OIDC/MFA, live provider
consent and connectors, real customer records, settlement, signed credit
approvals, independent finance-policy approval and operational security sign-off
remain separately gated. Source-health, scenario comparison, evidence tasks and
portfolio exports are tracked in #160 through #163.
